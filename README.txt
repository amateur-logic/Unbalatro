UnBalatro 2.0.0 - custom jokers and decks for the Balatro3DS fan port.

Install: copy this whole UnBalatro folder into /3ds/save/Balatro3DS/sdmc/mods/
Then launch the game; Options > Mods should list UnBalatro.

15 Jokers: Aces Up, Triggered, Wizard, Bizarro, Perkeo Jr., Infinity, Freedom, Sisyphus,
Hyperspace, Mario, Luigi, Link, Samus Aran, Kirby, Donkey Kong.
10 Decks: Conjurer, Vagabond, Stacked, Adventurer, Faceoff, Patio, Collector, Hei,
Elevated, Jockler.
